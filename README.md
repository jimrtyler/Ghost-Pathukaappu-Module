# 👻 Ghost பாதுகாப்பு தொகுதி
**PowerShell-அடிப்படையிலான Windows & Azure பாதுகாப்பு வலுப்படுத்தல் கருவி**

> **Windows முடிவுப்புள்ளிகள் மற்றும் Azure சூழல்களுக்கான முன்கூட்டிய பாதுகாப்பு வலுப்படுத்தல்.** Ghost அனாவசிய சேவைகள் மற்றும் நெறிமுறைகளை முடக்குவதன் மூலம் பொதுவான தாக்குதல் வெக்டர்களை குறைக்க உதவும் PowerShell-அடிப்படையிலான வலுப்படுத்தல் செயல்பாடுகளை வழங்குகிறது.

## ⚠️ முக்கியமான பொறுப்புத்துறப்புகள்

**சோதனை தேவை**: Ghost ஐ எப்போதும் முதலில் உற்பத்தி அல்லாத சூழல்களில் சோதிக்கவும். சேவைகளை முடக்குவது சட்டபூர்வமான வணிக செயல்பாடுகளை பாதிக்கலாம்.

**உத்தரவாதம் இல்லை**: Ghost பொதுவான தாக்குதல் வெக்டர்களை இலக்காகக் கொண்டாலும், எந்த பாதுகாப்பு கருவியும் அனைத்து தாக்குதல்களையும் தடுக்க முடியாது. இது ஒரு விரிவான பாதுகாப்பு உத்தியின் ஒரு கூறு.

**செயல்பாட்டு தாக்கம்**: சில செயல்பாடுகள் கணினி செயல்பாட்டை பாதிக்கலாம். வெளியிடுவதற்கு முன் ஒவ்வொரு அமைப்பையும் கவனமாக மதிப்பாய்வு செய்யவும்.

**தொழில்முறை மதிப்பீடு**: உற்பத்தி சூழல்களுக்கு, உங்கள் நிறுவனத்தின் தேவைகளுடன் அமைப்புகள் ஒத்திசைக்கப்படுவதை உறுதிசெய்ய பாதுகாப்பு நிபுணர்களுடன் ஆலோசிக்கவும்.

## 📊 பாதுகாப்பு நிலப்பரப்பு

Ransomware சேதம் **2025 இல் $57 பில்லியனை** அடைந்தது, பல வெற்றிகரமான தாக்குதல்கள் அடிப்படை Windows சேவைகள் மற்றும் தவறான கட்டமைப்புகளை சுரண்டுகின்றன என்று ஆராய்ச்சி குறிப்பிடுகிறது. பொதுவான தாக்குதல் வெக்டர்கள் அடங்கும்:

- **90% ransomware சம்பவங்கள்** RDP சுரண்டலை உள்ளடக்கியது
- **SMBv1 பாதிப்புகள்** WannaCry மற்றும் NotPetya போன்ற தாக்குதல்களை செயல்படுத்தியது
- **ஆவண மேக்ரோக்கள்** ஒரு முதன்மை மால்வேர் விநியோக முறையாக இருக்கின்றன
- **USB-அடிப்படையிலான தாக்குதல்கள்** காற்று-இடைவெளி நெட்வொர்க்குகளை தொடர்ந்து இலக்காகக் கொள்கின்றன
- **PowerShell துஷ்பிரயோகம்** சமீபத்திய ஆண்டுகளில் கணிசமாக அதிகரித்துள்ளது

## 🛡️ Ghost பாதுகாப்பு செயல்பாடுகள்

Ghost **16 Windows வலுப்படுத்தல் செயல்பாடுகள்** மற்றும் **Azure பாதுகாப்பு ஒருங்கிணைப்பு** வழங்குகிறது:

### Windows முடிவுப்புள்ளி வலுப்படுத்தல்

| செயல்பாடு | நோக்கம் | கருத்தில் கொள்ளல்கள் |
|----------|---------|----------------|
| `Set-RDP` | Remote Desktop அணுகலை நிர்வகிக்கிறது | தொலைநிலை நிர்வாகத்தை பாதிக்கலாம் |
| `Set-SMBv1` | பாரம்பரிய SMB நெறிமுறையை கட்டுப்படுத்துகிறது | மிகவும் பழைய கணினிகளுக்கு தேவை |
| `Set-AutoRun` | AutoPlay/AutoRun ஐ கட்டுப்படுத்துகிறது | பயனர் வசதியை பாதிக்கலாம் |
| `Set-USBStorage` | USB சேமிப்பக சாதனங்களை கட்டுப்படுத்துகிறது | சட்டபூர்வமான USB பயன்பாட்டை பாதிக்கலாம் |
| `Set-Macros` | Office மேக்ரோ செயல்பாட்டை கட்டுப்படுத்துகிறது | மேக்ரோ-இயக்கப்பட்ட ஆவணங்களை பாதிக்கலாம் |
| `Set-PSRemoting` | PowerShell தொலைநிலையை நிர்வகிக்கிறது | தொலைநிலை நிர்வாகத்தை பாதிக்கலாம் |
| `Set-WinRM` | Windows Remote Management ஐ கட்டுப்படுத்துகிறது | தொலைநிலை நிர்வாகத்தை பாதிக்கும் |
| `Set-LLMNR` | பெயர் தீர்மான நெறிமுறையை நிர்வகிக்கிறது | பொதுவாக முடக்க பாதுகாப்பானது |
| `Set-NetBIOS` | TCP/IP மீது NetBIOS ஐ கட்டுப்படுத்துகிறது | பழைய பயன்பாடுகளை பாதிக்கலாம் |
| `Set-AdminShares` | நிர்வாக பகிர்வுகளை நிர்வகிக்கிறது | தொலைநிலை கோப்பு அணுகலை பாதிக்கலாம் |
| `Set-Telemetry` | தரவு சேகரிப்பை கட்டுப்படுத்துகிறது | நோயறிதல் திறன்களை பாதிக்கலாம் |
| `Set-GuestAccount` | விருந்தினர் கணக்கை நிர்வகிக்கிறது | பொதுவாக முடக்க பாதுகாப்பானது |
| `Set-ICMP` | ping பதில்களை கட்டுப்படுத்துகிறது | நெட்வொர்க் நோயறிதலை பாதிக்கலாம் |
| `Set-RemoteAssistance` | தொலைநிலை உதவியை நிர்வகிக்கிறது | helpdesk செயல்பாடுகளை பாதிக்கலாம் |
| `Set-NetworkDiscovery` | நெட்வொர்க் கண்டுபிடிப்பை கட்டுப்படுத்துகிறது | நெட்வொர்க் உலாவலை பாதிக்கலாம் |
| `Set-Firewall` | Windows ஃபயர்வாலை நிர்வகிக்கிறது | நெட்வொர்க் பாதுகாப்புக்கு முக்கியமானது |

### Azure கிளவுட் பாதுகாப்பு

```powershell

```

### அடிப்படை வலுப்படுத்தல் (முதலில் சோதிக்கவும்)
```powershell
# அத்தியாவசிய வலுப்படுத்தல் - முதலில் ஆய்வக சூழலில் சோதிக்கவும்

```

```powershell
# Group Policy வெளியீடு (டொமைன் சூழல்கள்)
Set-Ghost -SMBv1 -AutoRun -GroupPolicy

# Intune வெளியீடு (கிளவுட்-நிர்வகிக்கப்பட்ட சாதனங்கள்)
```


## 🔍 செயல்பாடு விவரங்கள்

### முக்கிய வலுப்படுத்தல் செயல்பாடுகள்

#### நெட்வொர்க் சேவைகள்
- **RDP**: தொலைநிலை டெஸ்க்டாப் அணுகலை தடுக்கிறது அல்லது போர்ட்டை சீரற்ற செய்கிறது
- **SMBv1**: பழைய கோப்பு பகிர்வு நெறிமுறையை முடக்குகிறது
- **ICMP**:정찰을 위한 ping பதில்களை தடுக்கிறது
- **LLMNR/NetBIOS**: பழைய பெயர் தீர்மான நெறிமுறைகளை தடுக்கிறது

#### பயன்பாட்டு பாதுகாப்பு  
- **மேக்ரோக்கள்**: Office பயன்பாடுகளில் மேக்ரோ செயல்பாட்டை முடக்குகிறது
- **AutoRun**: நீக்கக்கூடிய மீடியாவிலிருந்து தானியங்கி செயல்பாட்டை தடுக்கிறது

#### தொலைநிலை நிர்வாகம்
- **PSRemoting**: PowerShell தொலைநிலை அமர்வுகளை முடக்குகிறது
- **WinRM**: Windows Remote Management ஐ நிறுத்துகிறது
- **Remote Assistance**: தொலைநிலை உதவி இணைப்புகளை தடுக்கிறது

#### அணுகல் கட்டுப்பாடு
- **Admin Shares**: C$, ADMIN$ பகிர்வுகளை முடக்குகிறது
- **Guest Account**: விருந்தினர் கணக்கு அணுகலை முடக்குகிறது
- **USB Storage**: USB சாதன பயன்பாட்டை கட்டுப்படுத்துகிறது

### Azure ஒருங்கிணைப்பு
```powershell
# Azure குத்தகைதாரருடன் இணைக்கவும்
Connect-AzureGhost -Interactive

# பாதுகாப்பு இயல்புநிலைகளை இயக்கவும்
Set-AzureSecurityDefaults -Enable

# நிபந்தனை அணுகலை கட்டமைக்கவும்
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# சிறப்புரிமை பயனர்களை தணிக்கை செய்யவும்
Set-AzurePrivilegedUsers -AuditOnly
```

### Intune ஒருங்கிணைப்பு (v2 இல் புதியது)
```powershell
# Intune உடன் இணைக்கவும்
Connect-IntuneGhost -Interactive

# Intune கொள்கைகள் வழியாக வெளியிடவும்
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

### சோதனை தேவைகள்
- **ஆய்வக சூழல்**: முதலில் தனிமைப்படுத்தப்பட்ட சூழலில் அனைத்து அமைப்புகளையும் சோதிக்கவும்
- **பட்டம் பட்டமான வெளியீடு**: பிரச்சினைகளை அடையாளம் காண படிப்படியாக வெளியிடவும்
- **மீட்டெடுப்பு திட்டம்**: தேவைப்பட்டால் மாற்றங்களை மீளமைக்க முடியும் என்பதை உறுதிப்படுத்தவும்
- **ஆவணப்படுத்தல்**: உங்கள் சூழலுக்கு எந்த அமைப்புகள் வேலை செய்கின்றன என்பதை பதிவு செய்யவும்

### சாத்தியமான தாக்கம்
- **பயனர் உற்பத்தித்திறன்**: சில அமைப்புகள் தினசரி பணிப்பாய்வுகளை பாதிக்கலாம்
- **பழைய பயன்பாடுகள்**: பழைய கணினிகளுக்கு சில நெறிமுறைகள் தேவைப்படலாம்
- **தொலைநிலை அணுகல்**: சட்டபூர்வமான தொலைநிலை நிர்வாகத்தின் மீதான தாக்கத்தை கருத்தில் கொள்ளுங்கள்
- **வணிக செயல்முறைகள்**: அமைப்புகள் முக்கியமான செயல்பாடுகளை உடைக்கவில்லை என்பதை சரிபார்க்கவும்

### பாதுகாப்பு வரம்புகள்
- **ஆழமான பாதுகாப்பு**: Ghost பாதுகாப்பின் ஒரு அடுக்கு, முழுமையான தீர்வு அல்ல
- **தொடர் நிர்வாகம்**: பாதுகாப்பு தொடர்ச்சியான கண்காணிப்பு மற்றும் புதுப்பிப்புகள் தேவை
- **பயனர் பயிற்சி**: தொழில்நுட்ப கட்டுப்பாடுகள் பாதுகாப்பு விழிப்புணர்வுடன் இணைக்கப்பட வேண்டும்
- **அச்சுறுத்தல் பரிணாமம்**: புதிய தாக்குதல் முறைகள் தற்போதைய பாதுகாப்புகளை மீறலாம்

## 🎯 தாக்குதல் காட்சி உதாரணங்கள்

Ghost பொதுவான தாக்குதல் வெக்டர்களை இலக்காகக் கொண்டாலும், குறிப்பிட்ட தடுப்பு சரியான செயல்படுத்தல் மற்றும் சோதனையைப் பொறுத்தது:

### WannaCry-பாணி தாக்குதல்கள்
- **தடுப்பு**: `Set-Ghost -SMBv1` பாதிக்கப்படக்கூடிய நெறிமுறையை முடக்குகிறது
- **கருத்தில் கொள்ளல்**: பழைய கணினிகள் எதுவும் SMBv1 ஐ தேவையாகக் கொண்டிருக்கவில்லை என்பதை உறுதிப்படுத்தவும்

### RDP-அடிப்படையிலான Ransomware
- **தடுப்பு**: `Set-Ghost -RDP` தொலைநிலை டெஸ்க்டாப் அணுகலை தடுக்கிறது
- **கருத்தில் கொள்ளல்**: மாற்று தொலைநிலை அணுகல் முறைகள் தேவைப்படலாம்

### ஆவண-அடிப்படையிலான மால்வேர்
- **தடுப்பு**: `Set-Ghost -Macros` மேக்ரோ செயல்பாட்டை முடக்குகிறது
- **கருத்தில் கொள்ளல்**: சட்டபூர்வமான மேக்ரோ-இயக்கப்பட்ட ஆவணங்களை பாதிக்கலாம்

### USB-வழங்கப்பட்ட அச்சுறுத்தல்கள்
- **தடுப்பு**: `Set-Ghost -USBStorage -AutoRun` USB செயல்பாட்டை கட்டுப்படுத்துகிறது
- **கருத்தில் கொள்ளல்**: சட்டபூர்வமான USB சாதன பயன்பாட்டை பாதிக்கலாம்

## 🏢 நிறுவன அம்சங்கள்

### Group Policy ஆதரவு
```powershell
# Group Policy பதிவு வழியாக அமைப்புகளை பயன்படுத்தவும்
Set-Ghost -SMBv1 -RDP -AutoRun -GroupPolicy

# GP புத்துயிர் பெற்ற பிறகு அமைப்புகள் டொமைன்-வ்यापியாக பயன்படுத்தப்படுகின்றன
gpupdate /force
```

### Microsoft Intune ஒருங்கிணைப்பு
```powershell
# Ghost அமைப்புகளுக்காக Intune கொள்கைகளை உருவாக்கவும்
Set-IntuneGhost -Settings $GhostSettings -Interactive

# கொள்கைகள் நிர்வகிக்கப்பட்ட சாதனங்களுக்கு தானாகவே வெளியிடப்படுகின்றன
```

### இணக்க அறிக்கை

```powershell
# பாதுகாப்பு மதிப்பீட்டு அறிக்கையை உருவாக்கவும்
Get-Ghost | Export-Csv -Path "பாதுகாப்பு-தணிக்கை-$(Get-Date -Format 'yyyy-MM-dd').csv"

```

## 📚 சிறந்த நடைமுறைகள்

### வெளியீடு முன்
1. **தற்போதைய நிலையை ஆவணப்படுத்தவும்**: மாற்றங்களுக்கு முன் `Get-Ghost` ஐ இயக்கவும்
2. **முழுமையாக சோதிக்கவும்**: உற்பத்தி அல்லாத சூழலில் சரிபார்க்கவும்
3. **மீட்டெடுப்பை திட்டமிடுங்கள்**: ஒவ்வொரு அமைப்பையும் எவ்வாறு மீளமைப்பது என்பதை அறிந்து கொள்ளுங்கள்

1. **பட்டம் பட்டமான அணுகுமுறை**: முதலில் பைலட் குழுக்களுக்கு வெளியிடவும்
2. **தாக்கத்தை கண்காணிக்கவும்**: பயனர் புகார்கள் அல்லது கணினி பிரச்சினைகளுக்கு கவனிக்கவும்
3. **பிரச்சினைகளை ஆவணப்படுத்தவும்**: எதிர்கால குறிப்புக்காக எந்தவொரு பிரச்சினையையும் பதிவு செய்யவும்
4. **மாற்றங்களை தொடர்பு கொள்ளுங்கள்**: பாதுகாப்பு மேம்பாடுகளை பயனர்களுக்கு தெரிவிக்கவும்

2. **ஆவணத்தை புதுப்பிக்கவும்**: பாதுகாப்பு கட்டமைப்புகளை தற்போதைய நிலையில் வைத்திருங்கள்
3. **செயல்திறனை மதிப்பாய்வு செய்யவும்**: பாதுகாப்பு சம்பவங்களை கண்காணிக்கவும்
4. **தொடர்ச்சியான மேம்பாடு**: அச்சுறுத்தல் நிலப்பரப்பின் அடிப்படையில் அமைப்புகளை சரிசெய்யவும்
